## Tips


#### Cleanup elastic-agent (standalone)  registry

`
rm -rf ${AGENT_HOME}/data/elastic-agent-eea63d/run/filestream-default/registry
`


#### Query registry

`
jq -r 'select( (.k | type) == "string" and (.v.meta.source != null)) | [.v.meta.source,(.k | split("::")[1])] | @tsv' log.json | sort | column -t 
`


#### Get checksum for fingerprint used by filestream for file identity

`
head -c 1024 /path/to/file.log | sha256sum

`
